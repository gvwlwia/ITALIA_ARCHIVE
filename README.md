## О проекте

ITALIA ARCHIVE — веб-ориентированная база знаний, посвящённая архитектурному наследию Италии. Проект предназначен для систематизации информации об архитектурных объектах, городах, стилях, исторических эпохах и архитекторах.

Система предоставляет возможности просмотра каталога архитектурных объектов, поиска материалов и изучения взаимосвязей между элементами архитектурного наследия.

## Технологии

- Python
- Django
- MySQL
- HTML
- CSS
- JavaScript

## Основные возможности

- Каталог архитектурных объектов Италии.
- Справочная информация о городах, стилях, эпохах и архитекторах.
- Просмотр статей, изображений и видеоматериалов.
- Глобальный поиск по материалам базы знаний.
- Администрирование содержимого через панель Django Admin.
